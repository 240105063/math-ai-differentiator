CurveLab AI — Quadratic Functions

Project Overview

CurveLab AI is an interactive mathematics learning website designed for Grade 9 students.

The main topic is Quadratic Functions.

The website supports differentiated learning by offering mathematical activities at three difficulty levels.

Three Learning Levels

Level 1 — Foundation

Simple exercises, basic explanations, and guided hints for beginners.

Level 2 — Standard

Grade-level quadratic function problems involving algebraic calculations and graph analysis.

Level 3 — Advanced

More challenging problems involving multi-step reasoning and real-world applications.

Main Features

* Three selectable difficulty levels
* Interactive quadratic function graphs
* Practice problems
* Answer checking and instant feedback
* Hints and mathematical explanations
* Responsive design for mobile devices and computers

Technologies Used

* HTML
* CSS
* JavaScript
* GitHub Pages

AI Integration Status

The website currently uses built-in mathematical logic and offline feedback.

The Gemini AI integration has not been activated. Dynamic AI-generated tasks and AI-assisted explanations require a separate backend and API configuration.

Educational Purpose

The purpose of this project is to demonstrate how a mathematical topic can be adapted to different student ability levels.

Students can learn at their own pace, receive appropriate support, and develop mathematical problem-solving skills.
